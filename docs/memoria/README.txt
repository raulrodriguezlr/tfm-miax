Plantilla para la elaboración de la memoria de los TFMs del 
Máster en Inteligencia Artificial y Computación Cuántica Aplicada a los Mercados Financieros (MIAX) del Instituto BME.

Se proporciona un ejemplo de uso de esta plantilla estructurada para proyectos cuantitativos y de machine learning.

Contenido:

  - Plantilla: tfm.cls (no es necesario editar este fichero, ya está configurado con los márgenes, estilos y logos de BME).

  - Ejemplo de uso de la plantilla: memoria_TFM.tex (hay que editar este fichero para poner: autor/a, tutor/a, título, convocatoria, resúmenes, agradecimientos, etc.).

  - Directorio para los ficheros de los capítulos: tex/ (hay que editar los ficheros de este directorio). La estructura está orientada a datos, metodología, experimentación y resultados. 
    Importante: hay un documento tex (declaracion_ia.tex) en el que hay que especificar el grado de uso de la IA en la elaboración del TFM (especialmente relevante si tu modelo de lenguaje escribió parte de tu modelo predictivo).

  - Directorio para las figuras: figs/ (no se debe cambiar el nombre de la carpeta). Se pueden almacenar las figuras en formato pdf, png o jpg (ideal para gráficas de backtesting, curvas ROC o diagramas de arquitectura). 

  - Directorio para la bibliografía: bib/ (no se debe cambiar el nombre de la carpeta). Hay que añadir las referencias al fichero bibliografia.bib utilizando formato BibTeX.
